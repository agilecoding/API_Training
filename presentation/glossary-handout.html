Tester checklist for any REST call

Status code correct? Headers (Content-Type)? Body fields and types? Missing/invalid/expired token (401/403)? Bad input (400/422)? Repeat the call (idempotency)? Non-existent id (404)? Timeout or dependency down (5xx)?
